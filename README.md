# Spring Boot Gradle Project

This is a basic Spring Boot project using Gradle.

## Build and Run

- To build the project: `./gradlew build` (or `gradlew.bat build` on Windows)
- To run the project: `./gradlew bootRun` (or `gradlew.bat bootRun` on Windows)

## Project Structure
- `src/main/java` - Application source code
- `src/main/resources` - Application resources
- `src/test/java` - Test source code

## Requirements
- Java 17 or higher
- Gradle (wrapper included)
